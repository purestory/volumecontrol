# VolumeControl

VolumeControl은 작업 표시줄에서 마우스 휠을 스크롤하여 시스템 볼륨을 편리하게 조절할 수 있는 가벼운 Windows 유틸리티입니다. 또한 시스템의 주요 하드웨어 상태를 실시간으로 보여주는 모니터링 오버레이 기능도 제공합니다.

## 주요 기능

- **작업 표시줄 볼륨 제어:** 작업 표시줄에 마우스를 올리고 휠을 위아래로 굴려 직관적으로 볼륨을 조절할 수 있습니다.
- **실시간 하드웨어 모니터링:** 작업 표시줄 우측에 다음과 같은 시스템 상태를 오버레이로 표시합니다.
  - CPU 사용률 및 온도
  - GPU 사용률 및 온도
  - 시스템 메모리(RAM) 및 비디오 메모리(VRAM) 사용량
  - 실시간 네트워크 트래픽 (업로드/다운로드 속도)
- **컴퓨터 종료 타이머:** 원하는 시간 뒤에 PC를 자동으로 종료할 수 있는 타이머 기능.
- **자동 실행 지원:** 윈도우 시작 시 자동으로 실행되도록 설정할 수 있습니다 (작업 스케줄러를 사용하여 UAC 알림 없이 실행).
- **화면 보호기 방지:** 화면 보호기나 절전 모드로 진입하는 것을 막아주는 옵션 제공.
- **다중 사용자 환경 완벽 지원:** 여러 사용자가 번갈아가며 사용하거나 빠른 사용자 전환(Fast User Switching) 시에도 문제없이 동작합니다.

## 시스템 요구 사항

- Windows 10 또는 Windows 11 (64비트)

## 설치 및 사용 방법

1. 제공된 `VolumeControl_Portable.zip` 파일을 다운로드하고 원하는 폴더에 압축을 풉니다.
2. `volumecontrol.exe`를 실행합니다. (하드웨어 모니터링 센서 접근을 위해 관리자 권한이 필요합니다.)
3. 시스템 트레이에 생성된 아이콘을 우클릭하여 **설정...** 메뉴로 들어갑니다.
4. "Windows 시작 시 자동 실행" 및 표시할 모니터링 항목들을 원하는 대로 설정합니다.

## 소스 코드 빌드 방법 (개발자용)

이 프로젝트는 메인 프로그램인 C++(`volumecontrol.exe`)과 하드웨어 정보를 수집하는 C# 래퍼 프로그램(`SysMonitorHost.exe` - LibreHardwareMonitor 사용)으로 구성되어 있습니다.

1. Visual Studio 2022로 `volumecontrol.sln` 솔루션을 엽니다.
2. `LHMWrapper` 프로젝트(C#)를 `Release` 모드로 빌드합니다. (필요 시 .NET 8.0 SDK 설치 필요)
3. `volumecontrol` 프로젝트(C++)를 `Release (x64)` 모드로 빌드합니다.
4. 모든 빌드가 완료되면 `x64\Release` 폴더에 최종 실행 파일들이 생성됩니다.
